# 未決定事項一覧

解決フラグは「済」= 判断が確定し正本へ反映済み。空欄 = 未決定。ID は詰めない。

| # | 項目 | 性質 | 重要度 | 決めること | 判断 | 解決フラグ |

| 2 | 対象 MC バージョン | スコープ | 高 | 同梱パレットの基準バージョン。複数バージョンを v1 で持つか | 当面 Java Edition 26.2 のみ。複数バージョン同梱は v1 ではしない | 済 |
