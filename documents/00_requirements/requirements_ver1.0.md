# 要件定義_ver1.0

## 本書の位置づけについて

本書は minecraft-pixelart の **Ver1.0 の正本**である。プロダクトの目的・機能の要否・線引きを書く。未決は `issue_list.md`。コードの正本ではない。

## 概要

画像を Minecraft のブロック配置に変換し、データパックとして書き出すツールキット。個人の単発スクリプト `pixel-art.py` を、他人が使える配布物にする。

対象ユーザーは、自分のワールドにドット絵を置きたい Java Edition のプレイヤー。Mod 必須にはしない。

## Ver1.0 で作るもの

- 画像ファイルを入力し、指定サイズのブロックグリッドへ写像する CLI
- 色の近いブロックを選ぶ（いまの `pixel-art.py` と同じ距離）
- 横方向の連続を `/fill` に圧縮する
- 相対座標または絶対座標
- 回転（0/90/180/270）と左右反転
- プレビュー画像の書き出し
- Minecraft データパック（`function` と `functions` の両方へ `build.mcfunction`）

## Ver1.0 で作らないもの

- Litematic / schematic / ワールド直接書き込み
- サーバーへ置く Web UI
- Bedrock Edition
- 有料アセットや非公式リソースパック前提の色

## パレット

ブロック色は Python に埋め込まない。Minecraft の client jar からブロックテクスチャの平均色を生成し、バージョン付きデータとして持つ。新しいブロックは jar を差し替えれば足せる。

配布物には、生成済みパレットを同梱する（利用者が毎回 jar を用意しなくてよい）。jar からの再生成はメンテナ向け。

生存向けなど、使うブロックを絞るフィルタを付ける（鉱石を使わない、など）。既定は「置きやすく、色のバリエーションがある固体ブロック」。液体・機能ブロック・非フルキューブは既定から外す。

## CLI の入力（選好・未確定は issue_list）

必須: 入力画像。任意: グリッドサイズ、回転、反転、相対/絶対、開始座標、データパック名、パレット/フィルタ。未指定はいまのスクリプトに近い既定。

実装は Claude または Gemini。GrokBot は要件と提案。確定した仕様だけを正本に載せる。
