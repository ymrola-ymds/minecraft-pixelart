# 要件定義_ver2.0

## 本書の位置づけについて

本書は minecraft-pixelart の **Ver2.0 の正本**である。Ver1.0（`documents/00_requirements/requirements_ver1.0.md`）の凍結仕様を引き継ぎ、Minecraft Java Edition 26.3 新規ブロック対応および透明ブロック制御オプションの要件・線引きを定義する。未決は `issue_list.md`。

## 概要

画像を Minecraft のブロック配置に変換し、データパックとして書き出す配布用 CLI。

対象は **Java Edition 26.3**（26.1 〜 26.3 スナップショット等に対応）。自分のワールドにドット絵を置きたいプレイヤー向け。Mod 不要。

配布の形は GitHub 上の PEP 723 スクリプト（`uv run` 等）。

## Ver2.0 で追加・更新するもの

- **Minecraft 26.3 / 26.2 新規ブロックの同梱パレット収録**
  - 辰砂シリーズ: `cinnabar`, `polished_cinnabar`, `cinnabar_bricks`, `chiseled_cinnabar`（4種）
  - ポプラ板材: `poplar_planks`
  - ペールオーク板材: `pale_oak_planks`
  - 樹脂シリーズ: `resin_block`, `resin_bricks`, `chiseled_resin_bricks`（3種）
  - ※ 新規追加された階段・ハーフブロック（ウール・コンクリート各色含む）、ポプラの棚・フェンス・ドア等、キノコ棚、ベッド等の非フルキューブ / 機能ブロックは除外。
- **透明ブロック（ガラス・色付きガラス）の利用有無オプション**
  - `--transparent-blocks` (`use` / `exclude`)
  - ドット絵において透過ブロックが混ざると背景（空や地形）が透けて絵が崩れるため、既定値は **使わない（`exclude`）** とする。
  - 対話実行時、未指定であれば利用者に確認する。非対話（非TTY / `--yes`）では既定値（使わない）を採用。
- **パレット抽出ツール（`tools/build_palette.py`）の 26.3 モデル仕様対応**
  - 26.3 の `assets/minecraft/models/block/*.json` におけるテクスチャの辞書形式（`{"sprite": "...", "force_translucent": true}`）に対応。

## Ver1.0 から引き継ぐもの

- LANCZOS 縮小、redmean 最近傍色差計算（ディザはしない）
- 横方向のラン圧縮（`/fill` / `setblock`）
- 配置の向き（床、壁・南/北/東/西）、相対/絶対座標
- 回転（0/90/180/270）および左右反転
- プレビュー画像出力（割当後ブロック色）
- データパック生成（`pack.mcmeta`、`function` と `functions` の両書き、65000 行分割）
- 落下ブロック（砂・赤い砂・砂利・コンクリートパウダー）の選択（CLI未指定時は対話確認、非対話時は使わない）

## 変換の流れ（v2）

1. 入力画像を読む。完全透明（アルファ 0）の画素は空気。それ以外は不透明化して扱う
2. 指定のブロック幅・高さへ LANCZOS で縮小する
3. 回転・左右反転する
4. パレットフィルタ（落下ブロック利用フラグ、透明ブロック利用フラグ）を適用した有効ブロック候補から、各セルの色に最も近いブロックを選ぶ（空気セルはスキップ）
5. 絵の横方向のランを `/fill`（長さ 1 なら `setblock`）に圧縮する。空気は置かない
6. 指定の向き（床または壁）と相対/絶対で座標を振る
7. 割当後のブロック色でプレビュー画像を書き、データパックを書き出す

## パレット

v2 の同梱パレットは `data/palette/palette_26.3.json`（対象ラベルは 26.3）。

**既定パレットから外すタグ**
- `liquid`（水・溶岩・粉末雪など）
- `functional`（レッドストーン機器、コンテナ、作業台系、TNT、スポナー、ベッド、ポータル、コマンド系など）
- `non_full_cube`（半ブロック、階段、柵、板ガラス、カーペット、ドア、棚など）
- `ice`、`slime`、`honey`、`leaves`

**利用者が選択するタグ**
- **落下ブロック (`gravity`)**: 砂・赤い砂・砂利・コンクリートパウダー。下に空間があると落ちるため選択。未指定時は対話確認。非対話時は使わない（`exclude`）。
- **透明ブロック (`transparent`)**: ガラス・色付きガラス（17種）。背景が透けて絵が崩れるのを防ぐため選択。未指定時は対話確認。非対話時は使わない（`exclude`）。

## CLI の入力

必須: 入力画像、出力するブロック幅と高さ。

任意と既定:
- 配置の向き: 未指定なら対話確認。非対話時は壁・南向き
- 落下ブロックを使うか (`--gravity-blocks`): 未指定なら対話確認。非対話時は使わない（`exclude`）
- 透明ブロックを使うか (`--transparent-blocks`): 未指定なら対話確認。非対話時は使わない（`exclude`）
- 回転: 0
- 左右反転: なし
- 座標: 相対
- データパック名 / 名前空間: 入力画像の stem を sanitize
- 関数名: `build`
- プレビュー: `<out>/previews/<画像名>.png`
- パレット: `data/palette/palette_26.3.json`（指定すれば旧版 `palette_26.2.json` も利用可能）
- `--yes`: 質問を出さずに既定を採用
